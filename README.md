# fzymgc-house Homebrew Tap

Homebrew formulae for fzymgc-house tools.

## Installation

```bash
brew tap fzymgc-house/tap
```

## Available Formulae

### router-hosts

CLI tool for managing DNS host entries on routers via gRPC.

```bash
brew install router-hosts
```

Or install directly without tapping:

```bash
brew install fzymgc-house/tap/router-hosts
```
